What changed
Completed provider periods are assessed separately BEFORE endpoint rejection
clears the active dataset. Their high/low and source-candle integrity checks run
per period: one invalid period cannot erase valid neighbouring periods.
Only periods whose calendar end is strictly earlier than the last printed chart
date are retained. Missing/invalid boundary dates, duplicate periods, unfinished
periods, invalid ranges and source-candle range violations are rejected.
Supported reference units: D1 -> months, H4 -> weeks, M1-H1 -> days.
Other timeframe reference units remain withheld rather than guessed.

The summary shows completed provider references separately from chart-verified
periods. JSON inventoryAuthority.completedPeriodReferences preserves per-period
evidence and rejection reasons. Missing current Fib authority still blocks entries.
References are NOT fed into the selector, bias calculation or current Fib frame.
A confirmed endpoint mismatch suppresses the reference display too.

Unavailable authority is no longer manufactured as a price conflict. It remains
a critical validation failure with its actual reason. Diagnostic-only runs skip
coaching diversity checks; full coaching runs retain those checks.

What this does NOT prove
Provider-reference prices are not broker-exact or screenshot-confirmed prices.
Range containment checks do not prove every historical candle was supplied.
The last printed chart date is still image-read evidence, not an exact endpoint.
This change does not resolve Platinum subscription access or infer missing dates.
The fixed-date OHLC tests are explicitly SYNTHETIC, not historical broker data.
No user-proposed prices or desired entries have been hardcoded.
